# FORM exercise assets

Each exercise gets its own folder.

Recommended filenames inside each folder:
- `machine.png` — how the machine looks
- `form-guide.png` — start/finish exercise illustration with working muscles highlighted
- `notes.md` — optional notes about the exact image/version

Keep filenames stable so the app can reference them directly. Replacing an image with a new file using the same filename lets the app update without changing the HTML.
